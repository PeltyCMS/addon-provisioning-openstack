**Tagline:** Provision OpenStack services from PeltyCMS orders

## OpenStack provisioning for PeltyCMS

Create, suspend, unsuspend and terminate customer services on OpenStack when orders are paid or cancelled. Credentials stay in Pelty secrets; the module runs as sandboxed WASM.

### Features
- Create / suspend / unsuspend / terminate
- Password + package sync hooks
- Works with Pelty product module mapping
- MythicCloud panel download supported

### Requirements
- Reachable OpenStack API/panel
- API token or login configured in Pelty
